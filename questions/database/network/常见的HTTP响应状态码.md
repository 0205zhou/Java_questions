# 常见的HTTP响应状态码

## 🧠 联想记忆法

### 记忆口诀/联想

**口诀：1 消息，2 成功，3 重定向，4 客户端，5 服务端。**

- **1xx**：先等等，我在处理
- **2xx**：好了，成功了
- **3xx**：去别处找
- **4xx**：你这边请求有问题
- **5xx**：我这边服务器出问题

### 记忆原理

状态码最容易混的是“谁的锅”。记住一句话：**4 开头多半是客户端问题，5 开头多半是服务端问题。** 再把最常见的几个具体状态码挂上去：200、301、302、304、400、401、403、404、500、502、503。这样面试时既能先讲大类，也能落到常见细项。

### 关联知识

- 与 **HTTP 请求流程** 关联
- 与 **浏览器缓存（304）** 关联
- 与 **认证和鉴权（401、403）** 关联
- 与 **网关和微服务（502、504）** 关联

## 📖 深度解答

### 核心概念

HTTP（HyperText Transfer Protocol，超文本传输协议）响应状态码，是服务器告诉客户端“这次请求处理结果如何”的标准编号。它不仅表示成功失败，还能表达重定向、认证失败、缓存命中、网关错误等语义。

### 底层原理

状态码分 5 大类：

| 范围 | 含义 | 说明 |
|---|---|---|
| 1xx | 信息性状态码 | 请求已收到，继续处理 |
| 2xx | 成功状态码 | 请求已成功处理 |
| 3xx | 重定向状态码 | 需要客户端进一步动作 |
| 4xx | 客户端错误 | 请求有问题 |
| 5xx | 服务端错误 | 服务器处理失败 |

### 实践应用

#### 1xx：信息性

- **100 Continue**：客户端可以继续发送请求体，常见于大文件上传前的预确认。

#### 2xx：成功

- **200 OK**：最常见，表示请求成功。
- **201 Created**：资源创建成功，常用于新增接口。
- **204 No Content**：成功但没有响应体，比如删除成功。

#### 3xx：重定向

- **301 Moved Permanently**：永久重定向，搜索引擎也会更新索引。
- **302 Found**：临时重定向，旧地址未来还可能恢复。
- **304 Not Modified**：资源未修改，浏览器可直接用本地缓存。

#### 4xx：客户端错误

- **400 Bad Request**：请求参数格式错误。
- **401 Unauthorized**：未认证，通常表示没登录或 Token 无效。
- **403 Forbidden**：已认证但无权限访问。
- **404 Not Found**：请求资源不存在。
- **405 Method Not Allowed**：请求方法不支持，比如该接口只允许 GET 却发了 POST。
- **408 Request Timeout**：客户端请求超时。
- **409 Conflict**：资源冲突，比如重复创建。

#### 5xx：服务端错误

- **500 Internal Server Error**：服务器内部异常，最常见的兜底错误。
- **501 Not Implemented**：服务端不支持该功能。
- **502 Bad Gateway**：网关拿到上游错误响应，常见于 Nginx（Engine X）或网关层。
- **503 Service Unavailable**：服务暂时不可用，比如限流、维护、熔断。
- **504 Gateway Timeout**：网关等待上游响应超时。

#### 文字架构图

```text
客户端发请求
   ↓
网关 / Nginx
   ↓
应用服务
   ↓
数据库 / 缓存 / 下游服务
```

- 请求参数错 → 常见 400
- 没登录 → 常见 401
- 没权限 → 常见 403
- 路由不存在 → 常见 404
- 应用异常 → 常见 500
- 下游超时 → 常见 502 / 504
- 服务限流或维护 → 常见 503

### 深入思考

1. **401 和 403 很容易混**：
   - 401：你还没证明你是谁
   - 403：我知道你是谁，但你不能访问
2. **304 不是错误码**，它属于重定向类，本质上是缓存协商结果。
3. **502 和 504 常考网关语义**：
   - 502 更偏“拿到了错误响应”
   - 504 更偏“等待超时”

## 🗺️ 回答思路

1. 先按 1xx 到 5xx 五大类概括含义。
2. 然后重点讲最常用的：200、301/302、304、400、401、403、404、500、502、503、504。
3. 最后补一句：4xx 多半是客户端问题，5xx 多半是服务端问题。
4. 如果面试官深挖，就重点展开 401 vs 403、502 vs 504、304 缓存机制。
